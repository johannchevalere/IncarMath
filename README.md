# IncarMath

**IncarMath** is a demonstrator of an immersive virtual reality environment designed to explore the learning of mathematical vectors through interactive and embodied manipulation.

The demo was developed as part of the IncarMath research project. It provides a proof-of-concept environment for visualizing and manipulating vectors and exploring basic vector operations in immersive virtual reality.

## Status

This repository contains a **demonstration prototype** developed during the project. It should not be considered a finalized educational application or an experimentally validated learning tool.

The project is no longer under active development and the software is not currently maintained.
